A complete computer built in FPGA logic

The custom RISC-V CPU runs firmware that reads a keypad, controls an AES-128 accelerator through memory-mapped registers, and sends the result to an OLED.

The CPU gives the encryption job to a dedicated circuit. How much work does that save?

Existing keypad-to-external-OLED demonstration: user-reported physical PASS. The new onboard OLED image awaits its lab check. Benchmark firmware is currently simulation-verified and not yet integrated into the board display.

Both paths include per-block key processing, input reads and output storage. Hardware timing includes key/plaintext register writes, START, status polling and ciphertext reads. Startup, display and UART are excluded. Two CPU-readable timer snapshots are checked against an independent simulation clock count.

Software baseline: compact byte-oriented C AES compiled with GCC -Os. This is a comparison against this implementation, not a claim against the fastest possible software AES.
